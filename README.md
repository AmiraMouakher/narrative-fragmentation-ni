# Narrative Fragmentation & Political Instability

Research code and reproducibility materials accompanying the study **Political Instability and Narrative Fragmentation as a Coupled System: An AI-Enabled Analysis of Northern Ireland**.

Authors: Nuno Morgado, Amira Mouakher, and Zoltán Oszkár Szántó.

This repository contains the analysis notebooks, data extracts, figures, reference results, documentation, and reproducibility utilities for the Northern Ireland narrative-fragmentation study (2015–2025).

See the repository directories for the full analysis workflow and reproducibility materials.
